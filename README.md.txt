# Python Analysis – Olist E-commerce Analytics

## Overview

This folder contains the Python notebook developed for the Olist E-commerce Data Analytics project.

Python was used for dataset inspection, data cleaning, validation, preprocessing and exploratory business analysis.

## Project Notebook

**File:** `notebooks/olist_ecommerce_data_analysis.ipynb`

The notebook contains the Python-based data preparation and analytical workflow.

## Key Activities

- Loaded and inspected the Olist dataset.
- Examined dataset dimensions and data types.
- Identified missing and duplicate values.
- Cleaned and validated data.
- Handled product and category inconsistencies.
- Analyzed delivery performance.
- Prepared datasets for business analysis.
- Generated analytical outputs for further reporting.

## Python Libraries

- Pandas
- NumPy
- Matplotlib

## Tools Used

- Python
- Google Colab
- Jupyter Notebook

## Output

The cleaned and analyzed data supported further analysis using MySQL, Excel and Power BI.
