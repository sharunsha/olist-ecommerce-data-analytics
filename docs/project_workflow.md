Olist E-commerce – Project Workflow
1. Project Overview
This project follows an end-to-end data analytics workflow using the Brazilian Olist e-commerce dataset.
The objective is to transform raw e-commerce data into meaningful business insights using Python, MySQL, Excel and Power BI.
2. Dataset Collection
•	Obtained the Brazilian Olist e-commerce dataset.
•	Worked with nine source tables.
•	Reviewed dataset structure, columns and record counts.
3. Data Cleaning and Preparation – Python
Tools: Python, Pandas, NumPy
Activities:
•	Loaded and inspected source datasets.
•	Checked missing and duplicate values.
•	Identified invalid and inconsistent records.
•	Cleaned product and category information.
•	Validated delivery dates and product attributes.
•	Prepared analytical datasets for further analysis.
4. Database Development – MySQL
Tools: MySQL, MySQL Workbench
Activities:
•	Created the olist_analytics database.
•	Created and populated relational tables.
•	Validated imported data.
•	Developed SQL queries using joins, aggregations, subqueries, CTEs and window functions.
•	Created reusable analytical views.
5. Business Analysis – SQL and Python
Analyzed six business areas:
1.	Revenue and business performance
2.	Product and category performance
3.	Delivery and logistics
4.	Customer satisfaction
5.	Customer segmentation using RFM analysis
6.	Seller performance
6. Excel Analytics
Tool: Microsoft Excel
Activities:
•	Prepared analytical worksheets.
•	Calculated business metrics and KPIs.
•	Performed trend and performance analysis.
•	Created 11 charts across the six analytical areas.
7. Interactive Dashboards – Power BI
Tools: Power BI Desktop, Power Query, DAX
Activities:
•	Developed the analytical data model.
•	Created table relationships.
•	Performed data transformations.
•	Developed DAX measures and KPIs.
•	Built two interactive dashboard pages.
8. Business Insights
Consolidated the findings into a final business report covering:
•	Revenue opportunities
•	Product-category performance
•	Delivery improvement opportunities
•	Customer satisfaction
•	Customer retention
•	Seller performance
9. Final Deliverables
Deliverable	Technology
Data cleaning and analysis	Python
Relational database and queries	MySQL
Business reporting and charts	Excel
Interactive dashboards	Power BI
Project documentation	Markdown / GitHub
10. Conclusion
The project demonstrates an end-to-end analytical workflow, from raw dataset preparation to business reporting and interactive visualization.
It applies practical data analytics techniques to identify business trends, operational challenges and customer-related opportunities in an e-commerce environment.
