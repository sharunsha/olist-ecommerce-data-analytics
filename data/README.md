# Dataset Information

This project uses the Olist Brazilian E-commerce Public Dataset.

The dataset contains information about customers, orders, products, sellers, payments, reviews, and delivery operations.

## Dataset Tables

- customers
- orders
- order_items
- products
- sellers
- payments
- reviews
- geolocation
- category_translation

## Data Source

The original dataset is publicly available for independent download.

Raw dataset files are not included in this repository.

## Usage

Download the dataset separately and place the required files in this folder before running the Python analysis or importing the data into MySQL.

Refer to the project documentation for the data preparation and analysis workflow.
